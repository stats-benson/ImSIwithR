# Dataset for Intermediate Statistical Investigations 

This is an R package that includes all the datasets used in the explorations in the textbook, *Intermediate Statistical Investigations*. The goal for this package is easy implementation into R where students are working on explorations. 

All credit is given to the authors of the book, Tintle, N., Chance, B. L., McGaughey, K., Roy, S., Swanson, T., and VanderStoep, J.  *Intermediate Statistical Investigations* is available from: VitalSource Bookshelf, Wiley Global Education US, 2020.

Package and all documentation created by Jacob Benson, a Mathematics-Statistics student at Whitman College, December 2025.
